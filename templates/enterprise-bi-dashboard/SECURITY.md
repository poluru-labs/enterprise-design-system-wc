# Security policy

## Supported versions

This template tracks the current `main` branch of
[enterprise-web-components-templates](https://github.com/poluru-labs/enterprise-web-components-templates).
Security fixes are applied to the latest published template only.

## Reporting a vulnerability

Do **not** open a public GitHub issue for security reports.

Email **mail.polurus@gmail.com** with:

- A description of the issue
- Steps to reproduce
- Affected files or routes
- Your suggested severity

You should receive an acknowledgement within 5 business days. Please give us
a reasonable window to investigate before any public disclosure.

## Scope notes

This repository is a **front-end demonstration template**. It ships fictional
metrics and has no backend, authentication server, or production data store.
Reports that only apply to a consumer’s later production wiring (their APIs,
SSO, or warehouse credentials) should be directed to that consumer.
