# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1.

## Our pledge

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of age, body size, visible or invisible disability,
ethnicity, sex characteristics, gender identity and expression, level of
experience, education, socio-economic status, nationality, personal
appearance, race, caste, color, religion, or sexual identity and orientation.

## Enforcement

Report unacceptable behavior to **mail.polurus@gmail.com**. The project
maintainer will review and respond as appropriate.

This code of conduct applies to all project spaces and when an individual is
representing the project in public.
