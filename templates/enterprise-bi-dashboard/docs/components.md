# Components

This template is a working catalog of
`@poluru-labs/enterprise-design-system-wc`. Every published `eds-*` tag is
used at least once.

## App shell

| Element | Where |
| --- | --- |
| `eds-side-nav` | Primary navigation |
| `eds-toolbar` | Top bar |
| `eds-breadcrumb` | Route trail |
| `eds-search` | Global and report search |
| `eds-dropdown-menu` + `eds-menu-item` | Account menu |
| `eds-button` / `eds-button-group` / `eds-split-button` | Actions |
| `eds-badge` / `eds-tooltip` | Notification affordances |
| `eds-drawer` | Advanced filters |
| `eds-modal` | Create alert |
| `eds-toast` via `showToast()` | Confirmations |

## Overview

`eds-alert`, `eds-stat`, `eds-card`, `eds-badge`, `eds-status`, `eds-tag`,
`eds-progress-bar`, `eds-circular-progress`, `eds-meter`, `eds-timeline`,
`eds-description-list`, `eds-divider`, `eds-link`.

## Reports

`eds-autocomplete`, `eds-combobox`, `eds-select`, `eds-date-picker`,
`eds-date-range-picker`, `eds-segmented-control`, `eds-data-table`,
`eds-pagination`, `eds-empty-state`, `eds-skeleton`, `eds-spinner`.

## Explorer

`eds-tree-view`, `eds-list` / `eds-list-item` (via `items`), `eds-tabs` /
`eds-tab`, `eds-accordion` / `eds-accordion-item`, `eds-code-snippet`.

## Query lab

`eds-stepper`, `eds-input`, `eds-textarea`, `eds-number-input`, `eds-slider`,
`eds-time-picker`, `eds-checkbox`, `eds-switch`, `eds-radio-group` / `eds-radio`,
`eds-file-upload`, `eds-pin-input`, `eds-kbd`.

## Alerts and settings

`eds-popover`, `eds-rating`, `eds-avatar`, `eds-icon`, `eds-visually-hidden`.

## Utilities used from the package

`showToast`, `setDensity`, `todayISO`, `formatCount`.

For property tables and events, use the package Custom Elements Manifest or
Storybook in the [design-system repository](https://github.com/poluru-labs/enterprise-design-system-wc).
