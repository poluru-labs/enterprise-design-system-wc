# Legal

This template ships the files most open-source and enterprise legal reviews
expect.

| File | Purpose |
| --- | --- |
| [LICENSE](../LICENSE) | MIT license text |
| [NOTICE](../NOTICE) | Copyright, third-party list, demo-data disclaimer |
| [AUTHORS](../AUTHORS) | Rights holder and contact |
| [COPYRIGHT](../COPYRIGHT) | Short copyright statement |
| [SECURITY.md](../SECURITY.md) | Private vulnerability reporting |
| [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [CONTRIBUTING.md](../CONTRIBUTING.md) | How to propose changes |
| [SUPPORT.md](../SUPPORT.md) | Docs and contact paths |
| [CHANGELOG.md](../CHANGELOG.md) | Release history |

The in-app `#/legal` route repeats the copyright, MIT summary, third-party
list, and demo-data disclaimer for people who never open the repository.

## What this does **not** grant

- A license to use third-party trademarks as your own
- Rights to ship Google Fonts binaries inside a closed distribution without
  following the SIL OFL
- Permission to treat fictional metrics as real financial or personal data

When you add a dependency, append it to `NOTICE` and this page.
