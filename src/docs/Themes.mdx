# Themes

The design system ships a **light** default and a **dark** theme.

## Storybook

Use the toolbar **Theme** switcher (addon-themes) to toggle `light` / `dark`. Dark mode applies the `eds-theme-dark` class on `body`.

## In your app

<Source
  language="html"
  dark
  code={`<!-- dark theme -->
<html class="eds-theme-dark">
  ...
</html>`}
/>

Or toggle at runtime:

<Source
  language="ts"
  code={`document.body.classList.toggle('eds-theme-dark', prefersDark);`}
/>
