# React

Use Enterprise Design Systems web components inside React as custom elements. React 19 improves custom element property/event support; React 18 works with a few binding notes below.

## Install

<Source
  language="bash"
  code={`npm install @poluru-labs/enterprise-design-system-wc lit`}
/>

## 1. Register elements + tokens once

In your app entry (`main.tsx` / `index.tsx`):

<Source
  language="tsx"
  code={`import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import App from './App';

import '@poluru-labs/enterprise-design-system-wc/tokens.css';
import '@poluru-labs/enterprise-design-system-wc';

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <App />
  </StrictMode>,
);`}
/>

## 2. TypeScript JSX types (optional but recommended)

Declare the custom tags so JSX type-checks:

<Source
  language="ts"
  code={`// src/eds-jsx.d.ts
import type { DetailedHTMLProps, HTMLAttributes } from 'react';

type EdsProps = DetailedHTMLProps<HTMLAttributes<HTMLElement>, HTMLElement> & {
  [key: string]: unknown;
};

declare global {
  namespace JSX {
    interface IntrinsicElements {
      'eds-button': EdsProps;
      'eds-input': EdsProps;
      'eds-alert': EdsProps;
      'eds-icon': EdsProps;
      'eds-modal': EdsProps;
      // add other eds-* tags you use
    }
  }
}

export {};`}
/>

## 3. Use in JSX

<Source
  language="tsx"
  code={`import { useEffect, useRef, useState } from 'react';

export function SaveBar() {
  const [email, setEmail] = useState('');
  const inputRef = useRef<HTMLElement>(null);

  useEffect(() => {
    const el = inputRef.current;
    if (!el) return;

    const onInput = (event: Event) => {
      const target = event.target as HTMLInputElement & { value?: string };
      // prefer detail when the component provides it
      const detail = (event as CustomEvent<{ value?: string }>).detail;
      setEmail(detail?.value ?? target.value ?? '');
    };

    el.addEventListener('eds-input', onInput as EventListener);
    return () => el.removeEventListener('eds-input', onInput as EventListener);
  }, []);

  return (
    <>
      <eds-input
        ref={inputRef}
        label="Email"
        type="email"
        value={email}
      />

      <eds-button
        variant="primary"
        onClick={(event) => {
          // Also listen for eds-click for component semantics
          console.log('native click', event);
        }}
        // @ts-expect-error custom event — attach via ref in React 18 if needed
        onEds-click={() => undefined}
      >
        Save
      </eds-button>
    </>
  );
}`}
/>

### React 18 event tip

React 18 does not automatically bind custom events like `eds-click` via `onEds-click`. Prefer **refs + `addEventListener`**:

<Source
  language="tsx"
  code={`import { useEffect, useRef } from 'react';

export function PrimaryButton({ onActivate }: { onActivate: () => void }) {
  const ref = useRef<HTMLElement>(null);

  useEffect(() => {
    const node = ref.current;
    if (!node) return;
    const handler = () => onActivate();
    node.addEventListener('eds-click', handler);
    return () => node.removeEventListener('eds-click', handler);
  }, [onActivate]);

  return (
    <eds-button ref={ref} variant="primary">
      Continue
    </eds-button>
  );
}`}
/>

### React 19

Custom elements generally receive properties and listen for custom events more cleanly. You can still use refs if a binding is unclear.

## 4. Controlled attributes / properties

Boolean attributes: pass the property when true; omit when false when possible.

## 5. Theme (light / dark)

<Source
  language="tsx"
  code={`import { useEffect, useState } from 'react';

export function useEdsTheme() {
  const [theme, setTheme] = useState<'light' | 'dark'>('light');

  useEffect(() => {
    document.documentElement.classList.toggle('eds-theme-dark', theme === 'dark');
  }, [theme]);

  return {
    theme,
    setTheme,
    toggleTheme: () => setTheme((t) => (t === 'dark' ? 'light' : 'dark')),
  };
}`}
/>

## Tips

- Import tokens + the package entry **once** at the root.
- Prefer refs for `eds-*` custom events on React 18.
- Children / slots: put content between tags (`<eds-button>Label</eds-button>`). Named slots use `slot="…"` on children.
- For a React-native API (`Button`, `ThemeProvider`, CSS modules), use `@poluru-labs/enterprise-design-system-react`.
