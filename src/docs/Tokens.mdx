# Design tokens

Tokens are the single source of truth for color, type, space, and motion. They ship as CSS custom properties (`--eds-*`) and as a typed TypeScript object.

## Usage

<Source
  language="css"
  dark
  code={`.card {
  background: var(--eds-color-surface);
  border: 1px solid var(--eds-color-border);
  border-radius: var(--eds-radius-lg);
  padding: var(--eds-space-6);
  box-shadow: var(--eds-shadow-sm);
}`}
/>

<Source
  language="ts"
  code={`import { tokens } from '@poluru-labs/enterprise-design-system-wc';

console.log(tokens.color.brand[700]); // #0f6e6a`}
/>
