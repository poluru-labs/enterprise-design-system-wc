# Enterprise Design System

A production-ready **Lit** web component library with shared design tokens, typography, Storybook documentation, and Controls.

Built for enterprise product teams that need framework-agnostic UI primitives with a clean, consistent visual language.

## What’s included

- **Tokens** — color, typography, spacing, radius, elevation, motion
- **Components** — Button, Tabs, Accordion, Modal
- **Storybook** — Controls, Docs, a11y checks, copyable source
- **TypeScript** — typed public API and CSS custom properties

## Design principles

1. **Clean over clever** — restrained surfaces, clear hierarchy, no visual noise  
2. **Token-first** — components consume CSS variables, never hard-coded one-offs  
3. **Accessible by default** — focus rings, keyboard support, ARIA roles  
4. **Framework agnostic** — native custom elements work in any stack
