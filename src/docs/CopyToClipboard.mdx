# Copy to clipboard

Every component story includes a **copyable HTML snippet**:

1. Under the canvas — dark **Snippet** panel with a **Copy** button  
2. In the Docs **Show code** panel — Storybook’s built-in copy control  
3. In MDX `Source` blocks — copy icon on the code fence  

Snippets update when you change **Controls**.

## How to copy

1. Open any component (for example **Button → Primary**).  
2. Find the **Snippet · html** panel below the preview.  
3. Click **Copy**.  
4. Or open **Docs** / **Show code** and use the copy icon there.

## Authoring snippets in stories

Stories set `parameters.snippet` via `withSnippet`:

<Source
  language="ts"
  code={`import { attr, withSnippet } from '../../storybook/snippet.js';

const meta = {
  parameters: {
    ...withSnippet((args) =>
      \`<eds-alert\${attr('variant', args.variant)}\${attr('title', args.title)}></eds-alert>\`,
    ),
  },
};`}
/>
